SEAL: Sparse Expert Routing with Additive Latent Reconstruction

for Compact, Non-causal, Single-channel Speech Separation

Xiang-Lin75 et al.

GitHub Repository Paper (arXiv)
Abstract: SEAL combines three design ideas for compact and efficient speech separation: (1) a shared-weight DPGRNN cell that iteratively updates a feature state; (2) refinement-aware Top-1 routing over stateless residual experts; (3) conservation-structured six-atom latent reconstruction with a bounded additive complex correction. The result is a highly competitive model for single-channel speech separation.
